# Gyilkosság a Szegfű-villában

Böngészős nyomozós játék Agatha Christie modorában.

Balatonfüred, 1931. október. Kendeffy Aurél bárót holtan találják a villája könyvtárában. Öt gyanúsított, négy rejtvény, és reggelig ki kell deríteni, ki a gyilkos.

## Játék

Nyisd meg az `index.html`-t bármelyik böngészőben, vagy játssz online a GitHub Pages oldalon.

## Felépítés

Egyetlen önálló HTML-fájl, telepítés és szerver nélkül. A játékállás a böngésző helyi tárolójában mentődik.
